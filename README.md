# 作业任务清单

面向小学生的「作业打卡 + 计时 + 护眼提醒 + 积分激励」网页应用。家长把老师发的作业整理后粘贴进来，孩子逐项打勾，系统自动记录用时、累计积分、生成历史档案。支持多孩子账号隔离，家长用 PIN 进后台。

纯本地运行：Flask + SQLite，一条命令启动，数据全部存在自己电脑上。

## 功能

**孩子端**
- 今日任务清单：按科目分组，区分必做/选做，展示图片、音频、视频、PDF 附件
- 计时：墙钟计时与单任务专注计时联动，暂停、自动接力下一项，暂停次数统计
- PDF 编辑器：矢量笔迹、缩放平移、多页导出，笔迹持久保存
- 每日习惯：倒计时、独立图标、单独积分，可区分工作日/周末
- 积分与奖励：积分规则可配、奖励兑换、6 枚成就徽章
- 历史统计：日历视图、每日详情、本月统计、近 7 天柱状图
- 护眼提醒（20/45/60 分钟可选，带音效）、语音播报、深色模式；全局采用米白底（#f6f2e9）、暖白卡片（#fffdf8）、暖灰字、16px 正文的护眼阅读配色；顶栏用浅暖砂色（#e8e1d0）、底栏用浅暖米色（#f2ecdf）与内容区形成清晰层次；主色为低饱和青蓝（#4b7791），避免高饱和蓝色刺激；深色模式可自行切换
- 移动端适配 + PWA，可加到手机主屏

**使用说明**（`/guide`，底部导航「📖 指南」）
- 按角色分页介绍用法：快速上手、孩子端、家长端、小应用，登录页也有入口
- **维护约定：每次新增或修改功能后，必须同步更新使用说明页面对应的章节，保持页面与实际功能一致**

**家长后台**（PIN 登录）
- 粘贴导入作业、手动添加、作业模板一键添加、任务编辑
- 星级评价、留言板、孩子管理（头像贴纸）
- 数据备份与恢复

**小应用**
- 汉字随机认读：按日期或人教版教材册次/课文抽字练习，含笔顺动画、错题本、间隔复习；课本生字按 2024 版写字表逐课拆分（含语文园地），每字配 1-2 个教材词语；新增「笔顺闯关」，跟写（带轮廓）→ 默写逐笔判定手写笔顺，写错的字自动进错题本
- 英语单词：外研版（一年级起点）一年级上册，按 Module 选词，支持看词选义、听音选词、拼写填空、字母排序，发音使用浏览器 TTS；答错的词自动收进顶部「错题本」，可标记已掌握或只练错词
- 两个应用的「清空错题本」均需连续确认 5 次，避免误触清空

## 技术栈

- 后端：Python 3 + Flask + SQLite（WAL 模式，`data/app.db`）
- 前端：原生 HTML/CSS/JS，无构建步骤
- 存储：任务在 SQLite；附件在 `attachments/`；小应用数据在 SQLite 的 `app_data` 表，按孩子隔离

## 快速开始

```bash
pip install flask
./start.sh          # 默认 8000 端口
./start.sh 9000     # 临时指定端口
```

启动后终端会打印局域网地址和一个二维码，同一 Wi-Fi 下的手机扫码即可访问。

首次使用：进入首页选择/创建孩子 → 用 PIN 进家长后台录入作业。

> **默认 PIN 是 `1234`，请第一时间在后台改掉。**
> 后台可以「关闭服务」，服务是按需启停的，关掉不会丢数据。

## 数据与备份

- **自动备份**：每天一份 JSON 存到 `backups/`，自动清理 30 天前的
- **完整备份**：后台「导出完整备份」生成 zip（含数据库 + 附件）
- **恢复**：后台「恢复」可上传 zip 或 JSON；恢复前会自动先备份一次
- 附件增长较快（每天 5 个附件约 1.5GB/年），建议定期导出完整备份
- 超过 10 天没做完整备份，页面会弹提示

## 积分规则（默认值，后台可改）

| 行为 | 积分 |
| --- | --- |
| 当天必做全部完成 | +30 |
| 家长评 ⭐⭐⭐ / ⭐⭐ | +20 / +10 |
| 完成单个习惯 / 全部习惯 | +5 / +5 |
| 完成选做题 | +10 |
| 连续打卡 7 天 / 30 天 | +50 / +200 |

兑换示例：100 分 = 30 分钟动画时间，200 分 = 周末出游，300 分 = 自选一本书。

## 作业录入格式

```
【日期】2026-10-14
【语文】
- [必做] 任务描述（附图：xxx / 附视频：xxx / 附音频：xxx / 附文件：xxx）
- [选做] 任务描述
【建议时长】30-40 分钟
```

可以直接把老师发的作业丢给 AI，用下面这段提示词整理成上面的格式：

> 按科目分组，用【】标记科目；每行写成 `- [必做/选做] 描述（附件类型：说明）`；"见图/视频/PDF/音频"分别写成对应的附件标记；没提到附件就不加标记；选做只保留老师明确说的；描述简洁，保留页数、数量、范围；不遗漏、不增项；末尾加【建议时长】。

## 说明与限制

- 服务是开发服务器（Flask 内置），1~3 人家庭使用足够，不适合公网高并发
- 局域网 http 下不支持 Service Worker、系统通知和推送
- 习惯倒计时在前端计时，切后台长时间可能导致偏差
- 微信推送、家长端小程序、原生 App 均未实现（需要公网部署）
